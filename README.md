# Linux VM (Android)
App que instala e roda distros Linux (arm64) via proot, sem root. O APK é gerado pelo GitHub Actions.
1. Crie um repositório no GitHub e envie estes arquivos.
2. Aba Actions > "Build APK" (roda a cada push, ou clique em Run workflow).
3. Baixe o artefato "LinuxVM-debug-apk", extraia e instale o APK no celular (arm64).
